# MindfulMe App 

**MindfulMe** is a simple Flask-based web application designed to help students and young professionals track and manage their mental health through daily check-ins. 

 **Live Demo:** (https://mindfulme-web-5.onrender.com/)

## Features
* User-friendly interface for daily mental health check-ins (Moods and Journals).
* RESTful API backend powered by Python and Flask.
* Dynamic inspirational quotes via external API integration.
* Visual analytics dashboard to track mood distribution over time.
